# Superstore-Sales Analysis (Interactive Dashboard using MS Excel)
## Project Overview
This project is an interactive Sales Performance Dashboard build using MS Excel to analyze Revenue performance across product categories, products, regions, customer segments, and months. The goal of this dashboard is to support quick decision making by transforming raw sales data into meaningful insights through KPIs and visual storytelling
## Business Objective 
•	Evaluate overall sales performance using key performance indicators.

•	Track total revenue and units sold.

•	Identify the highest revenue product categories and products.

•	Compare revenue across customer segments and regions

•	Examine monthly revenue trends.

•	Develop business driven recommendations to support business decisions.

## Tools and skills used
•	Microsoft Excel

•	Pivot tables

•	Pivot charts

•	Slicers (month, customer segment, region, product category)

•	Data cleaning and Formatting

•	Dashboard Design and layout

## Process
•	Verify data for missing values and anomalies and sort out the same.

•	Made sure data is consistent and clean with correct data type, data format.

•	Check for duplicates and blank rows.

•	Validate data and look for out liar.

•	Used VLOOKUP to collect product name from product name table.

•	Created pivot tables according to the business objective.

•	Merged all pivot tables into one dashboard and apply slicers for deeper analysis.

## Dashboard Insights
•	Technology generated the highest revenue across all categories.

•	West recorded the highest revenue by region.

•	April generated the highest monthly revenue while March was the lowest at revenue.

•	Office Machine was the top selling product.

•	Monthly revenue shows noticeable fluctuations indicating seasonal sales trend.

•	Corporate Segment contributed highest revenue across all segments.
